# How reliable is a 9-out-of-10 mastery gate?

A short analysis of how often a 10-question mastery gate passes or fails students by chance, and what changes when the bar is lowered.

**Key results**
- A student with true 90% accuracy fails a 9/10 gate about 26% of the time; a 75% student passes about 24% of the time.
- Lowering the bar to 8/10 cuts false fails to about 7%, but a 75% student then passes about half the time.
- No threshold on 10 questions keeps both errors low. A better option is to fold the gate's answers into an existing mastery estimate (e.g. Bayesian Knowledge Tracing from practice) instead of treating it as a standalone pass/fail test.
