# How reliable is a 9-out-of-10 mastery gate?

A short analysis of how often a 10-question, 90% mastery gate passes or fails students by chance, plus a cheap fix and a better approach using practice history.

**Key result:** a student with true 90% accuracy fails a 9/10 gate about 26% of the time; a 75% student passes about 24% of the time.
